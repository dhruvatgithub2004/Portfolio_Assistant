SECTION: PROJECT 1 — TRAVEL PLANNING AGENTIC CHATBOT
================================================================================
Category: Generative AI
Summary: A multi-agent travel concierge built with Google ADK that answers natural-language destination, place, and travel-news queries using live web search and map data.

Problem it solves: Planning a trip normally means juggling disconnected sources — search engines for destination ideas, review sites or maps for nearby hotels/restaurants/attractions, and news sites for time-sensitive events or advisories. This project consolidates these fragmented tools into one unified conversational interface, while demonstrating genuine multi-agent orchestration (not a monolithic chatbot).

Key features:
- Single conversational entry point replacing multiple travel platforms
- Real-time grounding via live web search, eliminating stale or hallucinated information
- Genuine multi-agent delegation architecture: a root agent delegates to a travel-inspiration specialist agent, which routes to dedicated news and places sub-agents
- Dual integration paths: an end-user UI (Streamlit) and a standards-based API (AG-UI)
- Streamed responses with conversational memory across turns

Architecture: The news sub-agent uses the Tavily API for live search; the places sub-agent queries OpenStreetMap/Overpass via Nominatim, using Haversine distance scoring to produce user-friendly proximity labels (e.g., "5 minutes away").

Technology stack: Python, Google ADK (agent framework), LiteLLM (model interface), FastAPI (backend), Streamlit (frontend), Tavily API (search), OpenStreetMap/Overpass/Nominatim (geospatial data), DeepSeek Chat (LLM).

Challenges addressed: precise query routing to the correct sub-agent, maintaining search relevance/currency, converting geodata into human-friendly distance descriptions, and keeping behavior consistent across the Streamlit and AG-UI implementations.

SECTION: PROJECT 2 — MEDICAL COST PREDICTION
================================================================================
Category: Data Science
Summary: A regression pipeline predicting medical insurance costs with 99% accuracy (R² score), deployed as an interactive Streamlit app and containerized with Docker.

Problem it solves: Insurance providers need precise, instant, data-driven cost estimates rather than slower manual actuarial approaches. This project predicts an individual's insurance charges from their personal/health attributes.

Dataset: A public medical insurance dataset with features including age, BMI, smoking status, number of dependents, region, and sex (mix of numerical and categorical inputs). Target variable: annual insurance charges (continuous).

Key findings from exploratory data analysis:
- Smoking status is the strongest predictor of insurance charges
- BMI shows a positive correlation with charges, particularly above 30
- Age has a steady positive relationship with cost
- Region and sex have minimal impact on the variance in charges

Models tested: Linear Regression, Ridge, Lasso, and Random Forest Regressor, tuned with GridSearchCV and validated via cross-validation to prevent overfitting.

Results: R² score of 99% on the test set, with low RMSE and consistent cross-validation results. Smoking status was confirmed as the dominant predictive feature.

Technology stack: Python, Scikit-learn, Streamlit, Docker.

Deployment: An interactive Streamlit application (sliders/dropdowns for input) containerized with Docker.

SECTION: PROJECT 4 — CREDIT CARD DEFAULT PREDICTION
================================================================================
Category: Data Science
Summary: A classification model predicting credit card default risk, deployed as an interactive Streamlit application for financial risk assessment.

Problem it solves: Banks face significant financial risk from credit card defaults. This project identifies high-risk customers before they default, enabling interventions such as payment plans or credit limit adjustments.

Dataset: 1,000 customer records with 87 columns, including income, savings, debt, expenditure ratios (e.g., R_DEBT_INCOME), and category spending (e.g., T_GROCERIES_12). Composition: 51 float, 34 integer, 2 object columns (~679.8 KB). Target: binary DEFAULT classification variable.

Methodology: Removed the non-predictive CUST_ID column; applied OrdinalEncoder for the CAT_GAMBLING category; used IQR-based outlier removal via box-plot inspection; applied SMOTE to oversample the minority "default" class (284 → 716 instances); used an 80/20 train-test split with StandardScaler normalization and PCA. Models tested: Random Forest (GridSearchCV-tuned), Support Vector Classifier (RBF kernel), K-Nearest Neighbors, Logistic Regression, a Voting Classifier ensemble (LR + RF + KNN + SVM), and a Bagging Classifier (100 estimators).

Results (testing accuracy / F1-score):
- Random Forest: ~70% (noted overfitting — 100% train accuracy vs. ~70% test)
- SVC: 71.6% accuracy, 0.059 F1-score
- Logistic Regression (best generalizer): 72.5% accuracy, 0.18 F1-score
- KNN: 71.1% accuracy, 0.115 F1-score

Key challenges: severe overfitting on Random Forest, class imbalance, high dimensionality (87 features), and weak F1-scores on the minority class.

Planned future improvements: stronger regularization and ensemble stacking, targeted feature selection instead of blanket PCA, classification threshold recalibration, and benchmarking against XGBoost/LightGBM.

Technology stack: Python, Scikit-learn, imbalanced-learn, Streamlit, Pandas.

Live demo: https://credit-card-default-vnefpkqkmorc73etupaf6r.streamlit.app/

SECTION: PUBLICATION — "AI-BASED ESG AUDITING SYSTEM – 'AUDITOR'"
================================================================================
Dhruv Desai is a published co-author of a peer-reviewed research paper titled "AI-Based ESG Auditing System – 'AudItor'."
 
Authors: Abir Rawat, Riya Matekar, and Dhruv Desai.
Dhruv Desai's affiliation on the paper: School of CS & IT, Jain (Deemed-to-be-University), Bengaluru, India.
Published in: International Journal of Advanced Research in Science, Engineering and Technology (IJARSET), ISSN 2350-0328, Volume 12, Issue 3, March 2025, pages 23132–23144. Publisher website: www.ijarset.com.
 
Abstract summary: The paper proposes "AudItor," an AI-powered ESG (Environmental, Social, and Governance) auditing system that automates the process of estimating a company's ESG score. It combines machine learning, Intelligent Document Processing (IDP), and natural language processing (NLP) to streamline audits while providing comprehensive assessments and actionable advice, enhanced by an integrated AI-driven advisory chatbot that gives companies tailored recommendations for sustainability improvement.
 
Problem addressed: Traditional manual ESG auditing is time-consuming and labor-intensive, prone to human error and inconsistency (no standardized methodology across industries), often gives companies a score without actionable guidance on how to improve, and struggles with the sheer volume of ESG-related data companies generate.
 
System design (two-phase approach):
1. ESG Score Estimation — AudItor ingests structured, up-to-date ESG guidelines from sources such as international organizations, government agencies, industry associations, and NGOs, then uses Intelligent Document Processing to sort and categorize both structured and unstructured company data (recognizing patterns in documents, identifying gaps/inconsistencies) to calculate an ESG score.
2. AI Advisory Chatbot — an optional chatbot session trained on the same input set gives companies tailored, real-time recommendations for improving their ESG performance.
 
Claimed advantages over comparable tools (RepRisk, IBM Envizi, AuditBoard, and similar platforms cited in the paper's literature review): cross-industry applicability with industry-specific benchmarking, a self-learning AI model that improves with each interaction, comprehensive handling of both structured and unstructured data, a user-friendly interface, and customizable stakeholder reports — addressing gaps like lack of personalization, limited real-time adaptability, and insufficient actionable advisory support that the paper identifies in existing ESG-auditing applications.
 
Machine learning / NLP techniques discussed as candidate technologies for the system: Random Forest and XGBoost for ESG score prediction; LSTM (a recurrent neural network) for ESG trend forecasting; Doc2Vec for converting ESG reports into structured numerical (vector) representations; Transformer-based models (self-attention) for extracting context-aware insights from ESG disclosures and regulatory documents; ESG-BERT, a domain-tuned BERT model, for financial/sustainability text classification; and T5 (Text-to-Text Transfer Transformer) for converting unstructured ESG text into structured, actionable insights. Evaluation metrics discussed: RMSE and R² Score for prediction accuracy, and Precision, Recall, and F1 Score for text classification quality.
 
Additional analysis in the paper: an economic feasibility / cost-benefit analysis covering data acquisition, AI model development, chatbot development, and operational costs, projecting that potential benefits (improved client satisfaction, cost savings, and return on investment from rising ESG-service demand) outweigh implementation costs.
 
Conclusion: AudItor is presented as a revolutionary approach to ESG auditing that automates the traditionally manual process, providing companies with accurate ESG scores alongside actionable recommendations, and improving the transparency and reliability of ESG audits as investor and regulatory demand for ESG compliance continues to grow.
